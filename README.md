# Kaliki Jayakrishnaa – Personal Portfolio Website

An ultra-modern, high-performance portfolio website showcasing experience, agentic AI architectures, machine learning projects, software engineering platforms, and academic achievements.

## Features
- **Modern Glassmorphic Dark UI**: Custom-tailored typography (`Plus Jakarta Sans` & `JetBrains Mono`), cyan/indigo gradient glows, and polished micro-interactions.
- **Key Metrics Dashboard**: Highlights high-impact outcomes (70% autonomous query resolution at Amazon, 99%+ accuracy, 92% BERT precision, 100% university scholarship).
- **Interactive Project Filter**: Categorize projects between **AI & Machine Learning** and **Platforms & Android**.
- **Contact Actions**: Instant one-click copy to clipboard for Email and Phone numbers with real-time toast alerts, direct `mailto:` and `tel:` links, and an interactive message dispatch form.
- **Embedded SVG Logos**: High-resolution vector logos for GitHub, LinkedIn, Amazon, and dev tech stacks.
- **Zero-Dependency Setup**: Pure standalone HTML5 with Tailwind CSS and vanilla JavaScript.

## How to Run Locally

You can open `index.html` directly in any web browser, or serve it using Python's built-in HTTP server:

```powershell
# Navigate to the portfolio folder
cd "C:\Users\jayak\.gemini\antigravity\scratch\portfolio"

# Start local server
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## Deployment Options
- **GitHub Pages**: Push this repository to `Jayakrishnaa/Jayakrishnaa.github.io` and enable Pages in repository settings.
- **Vercel / Netlify**: Drag-and-drop the `portfolio` folder or connect your GitHub repository for instant global CDN deployment.
